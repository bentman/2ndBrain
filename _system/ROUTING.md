# Routing

Use this when the destination is unclear.

## Default Destinations

- User facts, preferences, profile, boundaries -> `_user/`
- Unsorted quick notes -> `_user/data/inbox/`
- Time-based notes, weekly summaries, reminders -> `_user/data/journal/`
- Reusable concepts, lessons, references, gotchas -> `_user/data/knowledge/`
- Personal/life research and decisions -> `_user/data/life/`
- Active or archived project work -> `_user/data/projects/`

## Rule

Choose the smallest useful home. Link related files. Do not duplicate content.
