# Boundaries

Privacy and handling rules. The agent reads this before storing sensitive, personal, or work-derived information.

## Work
- Employer-confidential material: store only in `_user/work/`
- Never store: credentials, customer data, source code
- Backup: `_user/work/` stays on this machine

## Life
- Never store: credentials, account numbers, government IDs
- Other people: first names only, no health or financial details

## Across Spaces
- Work content never goes into `_user/life/`, and life content never goes into `_user/work/`.

## Reminders
- Raise open reminders during the weekly review
