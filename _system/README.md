# System Process

`_system/` is the portable process layer for 2ndBrain.

Read `AGENTS.md` first. Use these files only when more detail is needed.

## Files

- `interaction-style.md` - how to apply `_user/preferences.md`
- `ROUTING.md` - simple destination rules
- `workflows/research-capture.md` - capture research
- `workflows/project-kickoff.md` - start project folders
- `workflows/solution-design.md` - maintain project design work
- `workflows/knowledge-transfer.md` - create reusable explanations
- `templates/` - small copyable Markdown structures

## Rule

Keep `_system/` user-neutral. User facts, preferences, and private data belong in `_user/`.
