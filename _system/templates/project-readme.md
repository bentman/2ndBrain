# Project README Template

Use for `_user/[space]/projects/[name]/README.md`.

```markdown
# [Project Name]

**Summary:** [One line: what this is for]
**Status:** Planning | Active | On Hold | Complete | Dropped
**Started:** YYYY-MM-DD
**Next action:** [The single next concrete step]

## Purpose
[Why this project exists]

## Goals
- [Goal]

## Constraints
- [Constraint]

## Success Criteria
[How we know it worked]

## Related
- [Link]
```

Keep **Next action** current. When the project ends, add the outcome and date, then move the folder to `archive/`.
