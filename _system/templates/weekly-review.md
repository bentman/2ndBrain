# Weekly Review Template

Use for `_user/[space]/journal/[year]/[year]-W[week].md` (ISO week, two digits, for example `2026-W03`). One file per space per week.

```markdown
# [Year]-W[Week] ([space])

## Done
- [What moved forward]

## Projects
- [Project](link) - status, next action

## Decisions
- [Decision and why, or link]

## Learned
- [Lesson, with a link to the knowledge note if one was written]

## Next Week
- [Focus]

## Reminders
- [Date] [Item]
```

Keep it short. Link to notes and projects rather than repeating them.
