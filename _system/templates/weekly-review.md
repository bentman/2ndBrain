# Weekly Review Template

Use for `[domain]/journal/[year]/[year]-W[week].md`. One file per domain per week.

```markdown
# [Year]-W[Week] ([domain])

## Done
- [What moved forward]

## Projects
- [Project](link) - status, next action

## Decisions
- [Decision and why, or link]

## Learned
- [Lesson, with a link to the knowledge note if one was written]

## Next Week
- [Focus]

## Reminders
- [Date] [Item]
```

Keep it short. Link to notes and projects rather than repeating them.
