# Note Template

Use for knowledge notes: concepts, lessons, references, gotchas.

```markdown
# [Title that states the idea]

**Summary:** [One line a future reader can act on]
**Updated:** YYYY-MM-DD

## Key Points
- [Point]

## Details
[Practical explanation, example, or what happened]

## Gotchas
- [Non-obvious issue]

## Open Questions
- [Question]

## Sources
- [Source]

## Related
- [Link]
```

Only the title and summary are required. Skip sections that do not apply.
