# Weekly Review

Use this once a week per domain, or when the user asks for a review. Review work and life separately.

## Checklist

1. **Inbox** - process the domain's `inbox.md` and anything waiting in `_user/inbox.md` (`workflows/capture.md`).
2. **Projects** - for each active project: is the status right, and is there a next action? Close and archive what is finished or dropped.
3. **Areas** - anything needing attention this week?
4. **Someday** - skim `someday.md`: start a project, keep, or delete.
5. **Lint** - run the Lint list in `AGENTS.md`. Fix small things; list the rest.
6. **Journal** - write `[domain]/journal/[year]/[year]-W[week].md` using `_system/templates/weekly-review.md`.
7. **Log** - append `- [YYYY-MM-DD] review | W[week]` to the domain `log.md`.
8. **Backup** - if `_user/.git` exists, commit there (see Backup in `AGENTS.md`).

## Rule

Keep it to minutes, not hours. If the review keeps finding the same problem, change the process instead of fixing it by hand each week.
