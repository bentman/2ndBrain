# Capture

Use this for quick notes and for emptying the inbox.

## Quick Capture

Append to the domain's `inbox.md`, one item per line, newest at the bottom:

```markdown
- [YYYY-MM-DD] [note]
```

If the domain is not known and asking would interrupt, append to `_user/inbox.md` instead. That file is only a holding place.

Do not sort, rewrite, or ask questions at capture time. If the destination is already obvious, skip the inbox and file it directly.

## Process Inbox

First move the items in `_user/inbox.md` that belong to the active domain into its `inbox.md`, asking where it is not obvious. Leave the other domain's items for that domain's session. Then, for each item in the domain's `inbox.md`, top to bottom:

1. **Decide** - one of:
   - Delete: no longer useful
   - Project: add to an existing project's `notes.md`, or start a project
   - Area: add to the relevant file in `areas/`
   - Knowledge: add to an existing note, or create one
   - Someday: add one line to `someday.md`
   - Journal: time-based context for this week's entry
2. **File it** - follow Ingest in `AGENTS.md` (file, index line, log line).
3. **Remove** the item from the inbox.

Process one domain at a time. An empty inbox is the goal.

## Rule

Capture is cheap; filing is deliberate. Never leave an item in the inbox because it is hard to place. Ask, then file or delete.
