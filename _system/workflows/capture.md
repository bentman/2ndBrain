# Capture

Use this for quick notes and for emptying the inbox.

## Quick Capture

Append to `_user/inbox.md`, one item per line, newest at the bottom:

```markdown
- [YYYY-MM-DD] work: [note]
- [YYYY-MM-DD] life: [note]
- [YYYY-MM-DD] [note with no domain yet]
```

Do not sort, rewrite, or ask questions at capture time. If the destination is already obvious, skip the inbox and file it directly.

## Process Inbox

For each item, top to bottom:

1. **Domain** - work or life. If the item has no prefix and it is not obvious, ask.
2. **Decide** - one of:
   - Delete: no longer useful
   - Project: add to an existing project's `notes.md`, or start a project
   - Area: add to the relevant file in `areas/`
   - Knowledge: add to an existing note, or create one
   - Journal: time-based context for this week's entry
3. **File it** - follow Ingest in `AGENTS.md` (file, index line, log line).
4. **Remove** the item from the inbox.

Process one domain at a time. An empty inbox is the goal.

## Rule

Capture is cheap; filing is deliberate. Never leave an item in the inbox because it is hard to place. Ask, then file or delete.
